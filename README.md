# Bia Resgate: Assistente de Recuperação Financeira

> **Projeto prático desenvolvido por Marcelo Mazzero para o [Bootcamp da DIO & Bradesco sobre GenAI, Dados e Cibersegurança](https://www.dio.me/bootcamp/bradesco-dados-ciberseguranca-genai)**

---


## 1. Problema
No Brasil, mais de 80% das famílias encontram-se endividadas. O excesso de informações genéricas na internet e o estresse da cobrança dificultam a tomada de decisão clara. A inadimplência gera paralisia.

---


## 2. Solução
A **Bia Resgate** é um Assistente Virtual de IA (MVP) que atua como uma conselheira de triagem financeira. Ela não vende empréstimos e não julga. Utilizando uma base de conhecimento restrita e validada, ela ajuda o usuário a:
1. Mapear dívidas de forma fria e lógica.
2. Priorizar o pagamento com base em taxas de juros (ex: rotativo do cartão vs. financiamento).
3. Entender a diferença entre dívida de Pessoa Física (PF) e Pessoa Jurídica (PJ/MEI/Simples Nacional).

---


## 3. Como Executar este Projeto
1. Clone este repositório.
2. Instale as dependências: `pip install google-generativeai`
3. Configure sua chave de API do Google Gemini como variável de ambiente: `export GEMINI_API_KEY="sua_chave"`
4. Execute o assistente: `python src/app.py`
